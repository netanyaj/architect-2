# ChangeCard

A suggested change to the plan, from a chat request.

- **Contents:** a label, the change, its cost and timing, then Apply · Edit · Discard.
- **Nothing builds until Apply.** While a build runs, applied changes queue until it finishes.
- **Apply is a secondary button** when the screen already has a primary (for example a blocker). It becomes the primary only when the card is the screen's main task.
