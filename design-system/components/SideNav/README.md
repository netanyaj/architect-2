# SideNav

The tray side nav for pages outside a project.

- **Classes:** `.side`, `.brand`, `.nv` (with `.on` and `aria-current="page"`), `.nsec`, and `.nv .n` for counts.
- **Order:** Home · Projects · Agents · Connections · Marketplace · Usage, then Admin (Approvals, Governance; admins only).
- **At the bottom:** the credits card (left / total, reset date, Plans link), Help with its online state, then the account (which opens Settings).
