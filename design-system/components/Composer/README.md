# Composer

The message box for Home and Chat.

- **One row under the text:** + (files, Studio agents, tools or MCP) · "Talk first" toggle · model pill · spacer · Send.
- **On Home:**
  - context pills (Add files, agents or tools · Import a repo · Templates and prompts · Help me decide) sit inside the box, above that row;
  - the voice button stays;
  - Send is the labelled primary "Write the plan ↑".
- **In Chat:**
  - Send is a 36px round icon button labelled "Send";
  - the voice button is dropped, so nothing clips at 344px.
- **"Talk first":**
  - When on, Architect discusses and changes nothing.
  - When off, a request becomes a change card with its cost.
- **Queued messages** show above the composer.
