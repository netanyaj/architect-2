# ListRow

Rows inside a tray, used for projects, approval requests and ideas.

- **Classes:** `.tray` holds `.lrow` items, each with: icon tile · name and one meta line · tools (`.ini`) · status with the next action · `⋯` menu.
- **Show the next action**, not just the state: "Needs you: connect Gmail".
- **Selected rows** (master–detail) get a 2px ink border.
