# NeedsYouCard

A blocker with the one thing the user can do about it.

- **Classes:** `.need` holds a status icon (`.st` plus a status class), a name, one sentence on what happens until it's fixed, and one action.
- **The action:**
  - When the user can fix it, the action is a `.btn.pri.sm`, the screen's main button.
  - When they can only wait (approval), the action is a `.lnk` such as "Remind Jordan".
- **The sentence** always says what still works, so the user isn't left thinking everything is broken.
