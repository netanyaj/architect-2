# PreviewDock

Architect's tools for the preview, in one dark dock that floats at the bottom of the app frame.

- **Classes:** `.dock` with buttons (`.on` for the active size), `.vr` dividers and `.pb` for problems.
- **Contents:**
  - desktop and phone size;
  - "Point at something" (the element picker);
  - "N problems", which opens the console, where each error has "Fix with AI".
- **It never covers** the app's own primary controls. The app scrolls under it.
