# Banner

A state that affects the whole stage, placed at the top of the stage pane.

- **Paused or blocked:**
  - a surface card with a 1.5px ink border and a pause icon;
  - says what is kept, what is needed, and what is spent;
  - one primary ("Raise budget to 125 and continue"), then the alternatives.
- **Error:**
  - a 1.5px failed border;
  - says what happened, what is kept and what it cost;
  - Try again (primary), try another model, edit the request.
- **Question:**
  - a 1.5px attention border, with options as `.opt`;
  - used when Build waits for an answer.
