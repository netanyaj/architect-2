# HelpPanel

Help with Architect.

- **Where it opens:** from the side nav, and from "?" in every project header with that project attached.
- **Contents:**
  - a greeting that names what's stuck;
  - 3 suggested questions;
  - "Talk to a person" (creates a ticket, reply within one working day);
  - an ask field.
- **People online** uses `works` green with a dot and the words.
